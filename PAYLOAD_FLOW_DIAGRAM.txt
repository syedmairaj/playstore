8. ERROR HANDLING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    If something fails:

    ┌─────────────────────────────────────────────────────────────────┐
    │ Validation Errors:                                              │
    │   - Missing workspace_id → Error toast + console log            │
    │   - Empty content → Error toast + console log                   │
    │   - Invalid metadata → Error toast + console log                │
    │   → Button stays enabled, no changes made                       │
    │                                                                 │
    │ Network Errors:                                                 │
    │   - stageSignal fetch fails → Error toast + catch block         │
    │   - Supabase timeout → Handled by stageSignal utility           │
    │   → Button shows "Failed" state, auto-resets                    │
    │                                                                 │
    │ Database Errors:                                                │
    │   - Insert fails → Exception caught                             │
    │   - Constraint violation → Logged to console                    │
    │   → User sees "Failed" toast, retry enabled                     │
    └─────────────────────────────────────────────────────────────────┘
