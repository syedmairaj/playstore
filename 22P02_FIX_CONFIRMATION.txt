ISSUE:
  22P02: invalid input syntax for type json

ROOT CAUSE:
  Using PostgreSQL -> operator (returns JSONB)
  Instead of ->> operator (returns TEXT)

SOLUTION APPLIED:
  Line 84 in /app/api/workspaces/[workspaceId]/competitors/[competitorId]/keywords/route.ts

BEFORE (WRONG):
  .filter('metadata->competitor_id', 'eq', competitorId)
                      ↑↑
                      Returns JSONB (type mismatch)

AFTER (CORRECT):
  .filter('metadata->>\\'competitor_id\\'', 'eq', competitorId)
                      ↑↑↑↑
                      Returns TEXT (correct type)

════════════════════════════════════════════════════════════════════════════════

WHY THIS WORKS:

PostgreSQL JSON Operators:
  -> : Returns JSONB type (for nested object access)
  ->> : Returns TEXT type (for value extraction and comparison)

The filter() operator expects TEXT values, so we use ->>

Before:  metadata->competitor_id    returns JSONB  → Type mismatch → 22P02 error ❌
After:   metadata->>'competitor_id' returns TEXT   → Type match   → Success ✅
