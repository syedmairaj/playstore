# Dashboard Home

## Purpose
Logged-in overview that shows value immediately and guides next actions.

## Top Section
- Workspace switcher (if multiple).
- Current plan and usage.
- Quick actions: "Optimize listing", "Track keywords", "View alerts"

## Metrics Row
- ASO score.
- Keyword opportunities.
- Ranking changes.
- Review sentiment.
- Localization coverage.

## Recent Activity
- Latest keyword movements.
- New review insights.
- Recent optimizations.
- Pending alerts.

## Quick Actions Grid
- "Optimize listing"
- "Track new keywords"
- "Analyze competitor"
- "Review insights"
- "Localization suggestions"
- "View alerts"

## Recent Workspaces Section
- List of user's workspaces.
- App count and status per workspace.

## UX Rules
- Make it scannable.
- Show value in first 5 seconds.
- Prioritize action over deep analytics.
- Use cards and clear hierarchy.
