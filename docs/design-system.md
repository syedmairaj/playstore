# Design System

## Visual Style
- Clean SaaS aesthetic.
- Premium but minimal.
- Neutral surfaces.
- One strong accent color.
- Subtle gradients only when needed.

## Typography
- Large readable headings.
- Clear body text.
- Small labels for metadata.
- Strong contrast.

## Components
- Sidebar.
- Top bar.
- Metric cards.
- Score badge.
- Trend charts.
- Keyword table.
- Recommendation panel.
- Alert banner.
- Empty state panel.
- Primary and secondary buttons.

## Spacing Rules
- Use generous padding.
- Avoid crowded layouts.
- Keep cards aligned.
- Maintain consistent gaps.

## Interaction Rules
- Highlight the main action.
- Make hover states subtle.
- Use clear loading indicators.
- Show success and warning states clearly.
