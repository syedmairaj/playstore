# Build Plan

## Phase 1: Foundation
- Set up auth, dashboard shell, and app onboarding.
- Build the main layout, navigation, and shared components.
- Add workspace and app profile structure.
- Create the basic design system.

## Phase 2: Core ASO Features
- Add keyword tracking.
- Add AI title, short description, and long description generator.
- Add competitor analysis.
- Add review insights.
- Add ASO score calculation.

## Phase 3: Retention Features
- Add alerts for ranking and rating changes.
- Add weekly summaries.
- Add saved recommendations.
- Add task reminders and notes.

## Phase 4: Localization and Growth
- Add Arabic, English, and market localization suggestions.
- Add export and reporting features.
- Add agency-friendly client views.
- Add billing and plan limits.

## Phase 5: Launch Polish
- Improve onboarding.
- Refine copy.
- Optimize performance.
- Tighten visuals and spacing.
- Prepare for public launch.
