# Dashboard structure (PlayStore.xyz)

Principles: **one calm home**, **obvious next step**, **no widget walls**.

## Workspace home (`/[locale]/app/[workspaceId]`)

1. **Header** — Workspace name, plan, keyword usage, unread alert count. Three primary actions: Optimize listing · Track keywords · View alerts.

2. **ASO health (hero block)** — Single panel:
   - **Score 0–100** — Sum of five checklist items (20 points each): app connected, keywords tracked, two rank snapshots saved, AI listing draft created, at least one alert rule.
   - **Checklist** — Each row links to the screen that completes it (Settings, Keywords, Optimizer, Alerts). Done rows use a quiet green treatment; todo rows invite a click.

3. **At-a-glance metrics (one row)** — Four small cards only:
   - Keyword slots left on plan
   - Terms with movement (2+ snapshots)
   - AI listing drafts (count)
   - Alert rules (count)

4. **Two columns** — Recent activity (feed) · Latest keyword movement (top terms).

5. **Quick actions** — Six tiles; link to real routes where they exist (Reviews for themes + future rating alerts). “Coming soon” stays visually muted.

6. **Workspaces** — Switch context without leaving the page tone.

## Deep links (sidebar)

- **Keyword tracker** — Lists, snapshots, trends.
- **AI listing optimizer** — Title, short, long, CTAs; credits-aware.
- **Competitor spy** — Roadmap: richer gaps & exports.
- **Reviews** — Themes, sentiment; roadmap: rating trend alerts.
- **Alerts** — Ranking / threshold rules.
- **Settings** — Apps, team, billing.

## Roadmap alignment (product)

| Area            | Now                         | Next                          | Later              |
|----------------|-----------------------------|-------------------------------|--------------------|
| ASO score      | Checklist + 0–100 on home   | Weighted scoring, history     | Store conversion signals |
| Keywords       | Track + snapshots         | Opportunity scoring           | Share of voice hints |
| Listing AI     | Full draft generation       | Version diff, tone presets    | A/B experiment hints |
| Competitor     | Spy entry                   | Metadata + overlap exports    | Automated briefs   |
| Reviews        | Page shell / light insights | Rating alerts + themes        | Release-note assist |
| Localization   | Product-wide EN + AR UI   | Playbook per market           | Auto EN ↔ AR listing diff |

## UX rules

- Prefer **one primary task** per screen.
- **Generous whitespace**, **one type hierarchy**, **soft borders**.
- Empty states explain **one** next action.
- Avoid secondary charts until the core checklist is complete.
