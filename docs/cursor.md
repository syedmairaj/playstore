# Cursor Instructions

## Build Style
- Keep the code clean.
- Avoid overengineering.
- Prefer small reusable components.
- Keep naming consistent.
- Build as if a senior human developer made it.

## UI Direction
- Sleek and premium.
- Minimal but not sterile.
- Soft borders and subtle shadows.
- Clear hierarchy.
- Strong spacing.
- Friendly empty states.
- Better than enterprise clutter.

## Product Direction
- Prioritize simplicity.
- Focus on action over analytics noise.
- Make insights easy to understand.
- Keep the first-use experience fast.
- Make the product feel polished and human.

## Coding Behavior
- Reuse existing components.
- Ask before major architectural changes.
- Keep pages focused.
- Separate UI from logic.
- Use small, readable files.
- Optimize for maintainability.
