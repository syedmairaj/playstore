# Agents

## Product Agent
Owns product direction, scope, and feature priorities.

## UX Agent
Owns dashboard structure, flows, and simplicity.

## ASO Agent
Owns keyword strategy, metadata quality, and ranking logic.

## Data Agent
Owns keyword tracking, competitor data, review signals, and alerts.

## AI Copy Agent
Owns title, short description, long description, and localization suggestions.

## QA Agent
Owns consistency checks, edge cases, and UX clarity.

## Launch Agent
Owns onboarding, pricing, onboarding copy, and release readiness.
